Odoo Automated Support System Details

Engineering Workflow: ERP-Integrated Support Automation

During my internship at Hangry.ID, I was tasked with modernizing the customer engagement pipeline. I developed an automated support ecosystem by building custom modules on top of the Odoo ERP framework using Python.

1. Modular Development & Automation

My core contribution involved the end-to-end development of a custom "Support Hub" within Odoo. I wrote Python logic to automate ticket categorization and routing, ensuring that urgent customer queries were immediately escalated to the correct department without manual intervention.

2. Real-time Communication Features

I implemented a Real-time Live Chat system that integrated directly with the Odoo backend. Key technical achievements included:

  • Automated FAQ Logic: Built a keyword-matching engine that suggests relevant help articles to users instantly, reducing the volume of simple queries.
  • Live Dashboard: Created a custom dashboard for support agents to track active conversations and user history in a single view.
  • API Integration: Connected the Odoo support module with external communication channels to centralize user engagement.

Note: In accordance with Non-Disclosure Agreements (NDAs), proprietary business logic, internal database schemas, and specific customer data have been redacted. The descriptions focus on the architectural implementation of the Python/Odoo framework.

3. Strategic Market Analysis

Beyond the code, I utilized the data collected by the new system to conduct Market Analysis. I wrote scripts to identify trends in common customer issues, which helped the product team proactively mitigate operational risks and find growth opportunities.

Project Information

  • Category: ERP & Automation
  • Organization: Hangry.ID
  • Tech Stack: Python, Odoo, SQL
  • Project Date: Apr 2021 - Jan 2022
